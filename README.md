Game similar to NYT's spelling Bee, with some modifications
- You can play multiple games per day!
- Show answers feature - for checking which words you missed.
- Check on missed words by clicking on it.
- You can create your own custom list of alphabets - hint - NYT.

Limitations:
- It can be as good as the list of words, which is not ideal.
- If you find a better source of the word list, let me know
- you can add your own list just change words.js file.
